AAPKA PG — installable web-app package

This package is a Progressive Web App (PWA) version of the owner prototype.

To install on Android:
1. Publish these files to an HTTPS website (for example, a GitHub Pages site).
2. Open that HTTPS website in Chrome on Android.
3. Open Chrome's menu and choose "Install app" or "Add to Home screen".

The app can then launch from your home screen in a standalone window.
The prototype stores data locally in the browser on that device only.

Important limitations:
- This is not an APK file.
- It does not yet have cloud sync, secure login, OTP, payment gateway,
  document uploads, or multi-user support.
- Do not enter real tenant sensitive data until secure backend features exist.
