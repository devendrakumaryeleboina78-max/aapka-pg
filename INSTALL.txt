AAPKA PG PWA support files

Upload these files into the SAME repository folder as index.html:
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Then edit index.html:
1. Inside the <head> section, add:
   <link rel="manifest" href="/manifest.webmanifest">
   <meta name="theme-color" content="#38215f">

2. Just before </body>, add:
   <script>
     if ("serviceWorker" in navigator) {
       window.addEventListener("load", () => {
         navigator.serviceWorker.register("/sw.js");
       });
     }
   </script>

After committing, wait for Netlify to redeploy and test the website again in PWABuilder.
